# make-knowledge-cards · 知识卡片生成器

把一篇文章或本地 Markdown/TXT 文件，自动提炼成 5-8 张结构化知识卡片。

## 项目解决什么问题

读长文章时，核心知识点往往淹没在铺垫和重复里，看完记不住、复习没抓手。这个技能把文章"压缩"成一张张独立的知识卡片——每张只讲一个知识点，让你能快速抓住重点、做笔记，或当作复习卡自测。

## 主要功能

- 把文章提炼成 5-8 张卡片（数量以内容为准，信息不足时不凑数）
- 每张卡片含四个字段：**标题 / 核心知识 / 简明解释 / 例子或自测问题**
- 只提取真正重要的知识，自动去重，一张卡片一个知识点
- 严格忠于原文，不编造原文没有的信息
- 支持两种输入：直接粘贴文章，或给 `.md` / `.txt` 文件路径
- 无需任何脚本或第三方依赖，纯提示词驱动

## 安装方法

本项目是一个「技能（Skill）」，不是需要编译或 `pip`/`npm` 安装的程序，没有外部依赖。安装就是把这个技能文件夹放到你所用 AI 工具的技能目录：

1. 找到 `skills/make-knowledge-cards/` 文件夹；
2. 把它整个复制到工具的技能加载目录，例如：
   - **Claude Code**：`~/.claude/skills/`（用户级）或项目内的 `.claude/skills/`；
   - **Codex / OpenAI**：把其中的 `agents/openai.yaml` 放入 agent 目录（如 `~/.codex/agents/`）；
3. 重启工具或重新加载技能。

`SKILL.md` 是技能主体（提取规则 + 输出格式），`agents/openai.yaml` 是 Codex/OpenAI 界面的显示元数据。

## 使用方法

加载技能后，用下面任一方式触发：

1. **粘贴文章**：把文章文本直接发给 AI，说"生成知识卡片"。
2. **本地文件**：给出 `.md` 或 `.txt` 文件路径，说"把这个文件生成知识卡片"。

## 输入输出示例

### 输入（文章片段）

> 光合作用是绿色植物利用光能，把二氧化碳和水转化成有机物（主要是葡萄糖）并释放氧气的过程，主要发生在叶绿体中。

### 输出

## 卡片 1：光合作用的定义

- **核心知识**：光合作用是植物利用光能，把二氧化碳和水转化为有机物并释放氧气的过程。
- **简明解释**：这是植物"吃饭"的方式——把太阳光当能量来源，把空气中的二氧化碳和水加工成自身需要的糖类，同时排出氧气。
- **自测问题**：光合作用需要哪三种原料？（答案：光能、二氧化碳、水）

共 1 张卡片

> 上面是单知识点的最简示例；真实文章通常产出 5-8 张。更多样例见 `tests/` 目录。

## 目录结构

```
first-skill/
├── skills/
│   └── make-knowledge-cards/
│       ├── SKILL.md            # 技能主体：提取规则 + 输出格式
│       └── agents/openai.yaml  # Codex/OpenAI 显示元数据
└── tests/                      # 测试样例（"信息充足"与"信息不足"两类）
```

## 特性与限制

- ✅ 只提取真正重要的知识；一张卡片一个知识点
- ✅ 自动去重；不编造原文没有的信息；信息不足时不凑数
- ❌ 暂不支持网页抓取、PDF、Anki、图形界面
