# 知识卡片生成器

## 概述

把用户提供的一篇文章或本地 Markdown/TXT 文件，提炼成一张张结构化知识卡片，帮助用户快速掌握核心内容、做笔记或复习。

## 输入方式

支持两种输入，二选一：

1. **粘贴文本**：用户直接把文章内容粘贴在对话里。
2. **本地文件**：用户给出 `.md` 或 `.txt` 文件的路径，用 Read 工具读取全文。

若用户给出 PDF、网页链接等不支持的输入，明确告知"暂不支持"，并请用户转成文本或直接粘贴内容。

## 卡片格式

每张卡片严格包含四个字段：

1. **标题**：一句话概括这张卡片的知识点，简短、具体。
2. **核心知识**：用 1-2 句陈述这个知识点本身（最重要的定义、结论、方法或关键数据）。
3. **简明解释**：用 2-3 句讲清楚"为什么"或"怎么理解"，让零基础的人也能看懂。
4. **例子或自测问题**：二选一——给一个具体例子，或出一道能检验理解的自测题。

## 提取原则（最重要）

1. **只提取真正重要的知识**：跳过铺垫、客套、冗余叙述，优先保留概念、结论、方法、因果和关键数字。
2. **一张卡片只讲一个知识点**：一个知识点里若含两个独立概念，拆成两张卡片。
3. **删除重复内容**：原文反复强调的同一观点只保留一次；意思相近的卡片要合并。
4. **不能编造**：卡片内容必须全部来自原文，不得添加原文没有的信息、数据或结论。
5. **数量以内容为准，不凑数也不贪多**：卡片数量通常在 5-8 张。原文信息量少时，就少生成几张，不注水、不编造；原文知识点明显超过 8 个时，只保留最核心的 5-8 个，其余合并或舍弃。

## 工作流程

1. 读取或接收全文，判断文章主题与长度。
2. 通读全文，划出所有候选知识点。
3. 按"提取原则"过滤、去重、合并。
4. 确定最终卡片数量（以内容为准，通常 5-8 张）。
5. 按"卡片格式"逐张生成卡片。
6. 自查：每张卡片是否只讲一个点、是否有原文依据、是否与其它卡片重复。

## 输出格式

用 Markdown 输出，每张卡片一个二级标题，字段用加粗标签，最后附一行统计：

```markdown
## 卡片 1：<标题>

- **核心知识**：...
- **简明解释**：...
- **例子 / 自测问题**：...

## 卡片 2：<标题>

- **核心知识**：...
- **简明解释**：...
- **例子 / 自测问题**：...
```

最后一行：`共 N 张卡片`。

## 示例

输入：「光合作用是绿色植物利用光能，把二氧化碳和水转化成有机物（主要是葡萄糖）并释放氧气的过程，主要发生在叶绿体中。」

输出：

## 卡片 1：光合作用的定义

- **核心知识**：光合作用是植物利用光能，把二氧化碳和水转化为有机物并释放氧气的过程。
- **简明解释**：这是植物"吃饭"的方式——把太阳光当能量来源，把空气中的二氧化碳和水加工成自身需要的糖类，同时排出氧气。
- **自测问题**：光合作用需要哪三种原料？（答案：光能、二氧化碳、水）
